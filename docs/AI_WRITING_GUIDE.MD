# AI Agents 文档写作指南

[文档索引](README.md) · [开发行为规范](../AGENTS.md)

此文档供 AI Agents 编写、维护和审查 Rename Studio 文档时使用。目标是让读者找到可信答案并完成当前任务。保留项目特有约定，阅读范围由任务决定。

写作权限遵循[根级文档权限](../AGENTS.md#文档权限)：代码实现子代理仅提交建议，由主代理决定直接修改或按需委派文档任务。

## 内容归属与事实

- 优先更新已有主题页。[文档索引](README.md)负责内容归属；架构、API、测试方法和阶段记录各在所属页面维护，同一事实只保留一处完整定义，其他页面按需摘要并链接。
- 实现细节通过代码入口查阅，文档保留理解架构、调用契约和完成操作所需的信息。
- 按本次结论核对直接相关的代码、配置、契约或验证记录。默认以当前工作区为准，发布版本以指定标签或提交为准；纯措辞修改无需通读实现。
- 区分当前行为、设计要求、待实现方案和验证结果。文档陈旧时更新文档；实现违反契约时指出差异，不把缺陷改写成规范。判断强度与证据一致，未发布实现不写成已发布能力。
- 验证结论注明执行者、版本或工作区范围、环境、命令或场景及实际结果；静态核对、Mock、CI 和真实云盘验收分别说明证据范围。简单任务在交付说明中记录，复杂任务按需使用 [generated](generated/README.md)。
- 写到重命名流程时，保留[业务与安全不变量](ARCHITECTURE.md#业务与安全不变量)及对应 API 的差异：批量执行实时复核，单项遵循独立契约；未知写入先核对，不推断成功或盲目重试；HTTP 状态与逐项执行结果分别解读。
- 长期文档放入 `docs/` 对应主题目录，目录级 Agent 指令放在对应代码目录的 `AGENTS.md`。修改时直接更新现状，变更历史由 Git 保留；长期文档不该有“本次更新”、变更清单或累计测试结果。临时进度与验收记录按 [generated 规则](generated/README.md)管理，完成后清理。

## 不同类型文档的职责

写作时需要特别注意，不要超过该类型文档限定的职责范围：

- 面向使用者的公开文档（操作指南和教程），说明如何具体完成一个任务，不暴露无关的内部实现细节。
- 参考文档（Reference）：说明某项接口或配置的精确定义是什么，主要内容有“字段、约束、默认值、响应、错误、示例”。
- 架构文档（Architecture）：说明当前模块的职责、依赖和协作关系，以及核心流程、不变量与扩展点。

## 表达与防御性写作

使用自然、具体的中文。先给答案，再按读者任务补充条件、步骤和原因。操作说明使用界面名称，开发说明使用准确的技术术语；字段、枚举、错误码和代码标识符保持原样。结构按内容选择，段落用于解释，列表用于步骤或分类，表格用于比较或查询。关系或流程难以用文字说清时可使用 Mermaid 图，并配简短文字说明。

- 对免责、限定、提醒和自我解释做删除判断：影响事实、结论范围、因果、操作或重大风险理解的，就近简短保留；其余删除（例如无信息的免责、预防性澄清和自我辩护）或合并。
- 断言过强就收窄断言；证据不足就核查、限定该项或删去，不靠后续免责声明补救。
- 不制造假想反方、虚假平衡或无依据的“不是 A，而是 B”；不以“情况复杂”等空话回避已有证据支持的判断。
- 不训诫读者，不用“必须明白”“值得注意”等话语强调重要性；直接写事实、理由和动作。
- 精简时保留解释、例子和衔接，不按否定词数量删句，也不把复杂内容压成结论清单。

项目中的必要条件要具体表达。例如，写“响应丢失后先核对实际名称”，而非笼统归为失败；写“构建后从产物加载扩展，核对按钮、账号匹配和目录打开流程”，而非反复补充“构建通过不代表可用”。

## 导航与引用

- 维护 `docs/README.md` 作为文档导航与职责总入口，文档增删或职责调整时同步更新。每份文档可从[总索引](README.md)到达；API 子页由 [API 索引](api/README.md)逐级索引，临时页由 generated 索引登记。页首链接所属索引及直接相关文档。
- 新增、移动、删除页面或修改标题时，同步索引、返回链接、交叉引用及锚点；保留 API 显式锚点与既有资源结构。删除过时内容，不留无用途的占位页。
- 仓库内通常用相对链接，路径及扩展名大小写与目标一致，阅读入口使用可点击且说明目标的链接文字。代码链接指向文件或目录，历史证据可指向明确提交。
- **发布包 README 使用在线知识库链接。** 根 README 随 ZIP 分发，`docs/` 不在包内；指向知识库和 Wiki 的链接保留 GitHub 在线地址，包内文件可用相对链接。打包范围见[组包脚本](../scripts/build_release.py)。
- 外部事实优先引用相关官方页面，涉及版本差异时注明适用版本或查阅日期。截图与图示仅在帮助理解时添加，素材脱敏并随相关内容维护。

## 命令、示例与收尾

命令交代系统、Shell、工作目录和必要前提，注明预期观察点；代码块标注语言，可复制命令不混入提示符或伪输出。API 示例与参数和返回契约一致，区分省略、`null`、空值和默认值；写入、重置或删除示例说明后果并使用测试数据，凭据与真实账号信息需脱敏。

文档任务交付前检查授权范围内改动的事实、Markdown、链接目标、路径大小写及锚点，并同步受影响的文档和示例。交付说明写清主要变化、实际检查及待核验项；外部资料未同步时明确列出。验证与 Git 权限遵循 [AGENTS.md](../AGENTS.md)，不重复定义审批流程。
