## 使用写作技能

编写、修改、校对或审阅项目文档时，先读取并使用项目内的 [`tech-doc-style-chinese` 技能](../.agents/skills/tech-doc-style-chinese/SKILL.md)，按文档类型查阅技能的参考资料。项目约定以本页和 [AGENTS.md](../AGENTS.md) 为准。

## 内容归属与事实

- 长期文档放在 `docs/` 的对应主题目录，目录级 Agent 指令放在对应代码目录的 `AGENTS.md`。长期文档记录现状，变更历史由 Git 保留。临时进度与验收记录按 [generated 规则](generated/README.md) 管理，完成后清理。
- 按 [文档索引](README.md) 定位并优先更新已有主题页。架构、API、测试方法和阶段记录各在所属页面维护。同一事实只保留一处完整定义，其他页面按需摘要并链接。
- 实现细节通过代码入口查阅，文档保留理解架构、调用契约和完成操作所需的信息。
- 复杂的跨模块流程或依赖关系可用 Mermaid 图呈现，并配简短文字说明关键职责、条件或例外。示例见[后端依赖与对象装配](backend/ARCHITECTURE.md#依赖与对象装配)。
- 按本次结论核对直接相关的代码、配置、契约或验证记录。默认以当前工作区为准，发布版本以指定标签或提交为准；纯措辞修改无需通读实现。
- 文档陈旧时更新文档。发现实现与契约不一致时，指出差异并保留契约。
- 验证结论注明执行者、版本或工作区范围、环境、命令或场景及实际结果。静态核对、Mock、CI 和真实云盘验收分别说明证据范围。简单任务在交付说明中记录，复杂任务按需使用 [generated](generated/README.md)。
- 重命名流程文档遵循 [业务与安全不变量](ARCHITECTURE.md#业务与安全不变量)。批量执行实时复核，单项遵循独立契约。写入结果未知时先核对实际名称，不推断成功或盲目重试。HTTP 状态与逐项执行结果分别解读。

## 导航与引用

- 文档增删或职责调整时同步更新 [总索引](README.md)。API 子页由 [API 索引](api/README.md) 逐级索引，临时页由 generated 索引登记。页首链接所属索引及直接相关文档。
- [总索引](README.md) 不收入 Agents 协作文档，此类型文档在 Agents.md 中导航。
- 新增、移动、删除页面或修改标题时，同步索引、返回链接、交叉引用及锚点。保留 API 显式锚点与既有资源结构。
- 仓库内通常用相对链接，路径及扩展名大小写与目标一致，阅读入口使用可点击且说明目标的链接文字。代码链接指向文件或目录，历史证据可指向明确提交。
- **发布包 README 使用在线知识库链接。** 根 README 随 ZIP 分发，指向知识库和 Wiki 的链接保留 GitHub 在线地址，包内文件可用相对链接。打包范围见 [组包脚本](../scripts/build_release.py)。
- 外部事实优先引用相关官方页面，涉及版本差异时注明适用版本或查阅日期。截图与图示脱敏后随相关文档维护。

## 命令、示例与收尾

命令示例注明适用系统、Shell 和工作目录。代码块标注语言，提示符和输出放在可复制的命令块之外。API 示例按契约区分省略、`null`、空值和默认值。写入、重置或删除示例使用测试数据，凭据与真实账号信息脱敏。

交付前核对受影响的链接目标、路径大小写及锚点，并同步相关文档和示例。交付说明列出主要变化、实际检查、待核验项及尚未同步的外部资料。验证与 Git 权限遵循 [AGENTS.md](../AGENTS.md)。
