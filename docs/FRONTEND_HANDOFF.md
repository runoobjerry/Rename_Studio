# 前端交接文档

## 定位与阅读入口

本文件说明前端模块职责、已实现能力和长期维护约定。实现事实以当前代码为准，依赖版本、控件尺寸、具体文案和测试覆盖分别查源码与专门文档，不在此维护副本；已实现不代表已通过运行验收。

接力时先读根目录与 `frontend/AGENTS.md`，再按需要查阅本文件、[API 契约](API_REFERENCE.md)、[任务池](UI_TODO.md)和[当前快照](UI_STATE.md)，随后只读取目标模块及直接调用方。

## 模块职责与代码入口

以下路径均相对 `frontend/src/`。

| 入口 | 职责 |
|---|---|
| `App.tsx`、`WorkspaceApp.tsx` | 应用入口、Provider 组合、工作区/设置内存视图、布局、导航保护与跨 Hook 协调；没有 URL 路由或深层链接 |
| `workspace/hooks/useWorkspaceStorage.ts`、`workspace/workspaceSession.ts` | 连接与目录查询、本地根目录选择、默认云目录恢复/保存、标签会话路径记忆、手动刷新 |
| `features/rename/useRenameWorkflow.ts` | 有序有效选择与任务展示、预览 ID 生命周期、预览/执行请求、分批提示、结果通知及确认元数据合并 |
| `stores/useRenameStore.ts`、`types/index.ts` | 选择、规则链、当前会话任务/批次快照与逐项状态；API 类型 |
| `workspace/hooks/useFactoryReset.ts` | 重置禁用条件、请求状态、成功后的缓存和工作区清理 |
| `features/settings/{SettingsPage,StorageSettingsPanel}.tsx` | 外观、多连接配置、授权与重置确认 |
| `features/settings/{useAppSettings,useThemePreference}.ts` | 后端设置读取/串行保存、主题草稿与系统外观订阅 |
| `i18n/`、`locales/` | i18next 初始化、Vite 自动发现语言资源、浏览器语言解析、语言偏好及初次显示门控；日期/数字格式化 |
| `features/files/{FileBrowser,LocationBreadcrumbs}.tsx`、`fileSort.ts`、`defaultCloudLocation.ts` | 文件/任务成员表、排序比较、筛选与选择、路径导航、默认目录账号匹配 |
| `features/rules/{RuleEditor,RuleFields}.tsx` | 顺序规则链、添加菜单和显式字段配置 |
| `features/rename/{PreviewPanel,RenameActions,RenameActionsWithProgress}.tsx` | 预览/结果展示、确认执行、局部进度订阅 |
| `workspace/components/{StorageSidebar,StorageLocationPanel,BatchLimitDialog}.tsx` | 侧边栏、目录操作与分批提示展示；Drawer 容器由 WorkspaceApp 管理 |
| `components/`、`hooks/useVirtualTable.ts`、`theme.ts`、`styles.css` | 共享通知、筛选、图标按钮、表格虚拟化、主题与布局 |
| `api/client.ts` | 共享 HTTP 层和连接级 API 客户端 |

TanStack Query 管理服务端状态，Zustand 管理选择、规则与页面内存任务；筛选留在组件，文件排序由 WorkspaceApp 保存在页面内存并显式传给工作流与表格，不修改目录缓存。连接与重命名 Hook 不直接互相调用，由 WorkspaceApp 显式传入数据及重置动作，展示组件不承载任务状态机。

## 已实现能力与限制

- Local/OneDrive/Google Drive 多连接、目录浏览与刷新、文件/文件夹选择、面包屑导航、响应式侧边栏和设置页。选中文件夹只重命名文件夹本身，不递归处理内容。
- `padding`、`replace`、`remove`、`insert` 四种规则的字段编辑，以及启用/禁用、排序、复制、删除和清空。只展示前端已适配的规则；新增后端规则不会自动生成字段 UI。
- 服务端预览、冲突和无效名称展示、人工确认执行、逐项结果及分批任务。任务文件集合在首次预览固定，每批上限见 API 契约与 Store 常量；跨批次名称依赖由后端拒绝，不由前端复杂调度。现有规则不使用跨批次序号。
- 文件和预览表已有虚拟化。选择、筛选、统计及列宽基于完整数据，不能只按挂载行计算；进度查询局部订阅，避免更新整个工作区。
- 文件名和修改时间支持表头升降序排序，预览与任务分批使用同一顺序；具体约定见下方“选择、筛选和排序”。
- 主题、分批提示和默认云目录由后端应用设置持久化；任务和排序只在页面内存，刷新即丢失。没有持久化历史、撤销/重做、规则集 UI 或搜索；目录接口无前端分页，云盘分页由后端聚合。

## 必须保留的业务与交互约定

### 预览、执行和任务

- 先预览再确认执行，只提交服务端签发的 `preview_id`。预览不可由客户端改造，执行仍以服务端重校验为准；快照生命周期和错误码见 API 契约。
- 连接、目录、账号、连接版本、选择或规则变化使旧预览失效；过时预览应释放，迟到响应不能覆盖当前上下文。切换工作区清理任务和选择，规则链保留。
- 任务中的自动目录读取暂停，手动刷新保留。执行结果只合并 Provider 确认的 `current_file`，兼容 Local 路径 ID 改变，不按名称推断身份或成功。
- 完成项不能重复选择，失败项可重新预览；缺少完整执行响应或结果未知时锁定对应批次，禁止直接重试。用户须核对真实存储，再结束旧任务并重新选择；不提供自动重放或撤回。
- 无名称变化的批次也须确认执行才能记为完成。结束任务只丢弃当前会话记录，不撤销已发生的重命名。
- 超过单批上限时，点击预览才出现分批提示；取消不创建任务或提交预览。偏好保存失败撤销草稿并提示。
- 进度来自只读服务端查询；轮询失败不重新执行、不模拟增长。已处理数量包含失败，进度完成不等于全部成功，逐项结果为准。

### 选择、筛选和排序

- 文件筛选清除隐藏项的选择，取消筛选不恢复旧选择。全选/反选只作用于全部可见且可选择的项目，替换选择集合；没有可选择项时禁用批量选择。
- 目录成功刷新后，选择与完整目录取交集；不自动选择新增项，读取失败保留选择。选择收缩使旧预览失效，但不重置进行中的执行请求与进度。
- 预览筛选仅影响显示，不缩小执行范围；执行结果中的失败/跳过分别归入错误/无变化，成功结果将待修改标签切为已修改。
- 普通筛选无勾选时显示全部；任务开始后默认显示待处理项，类型组与状态组之间取交集，各组内部取并集，失败组包含待核对项。
- 排序复用 MUI TableSortLabel，箭头为 16px；默认完整文件名自然升序，Intl.Collator 使用浏览器语言列表（缺失时使用浏览器单语言，最后为 en-US），忽略大小写并按数字值比较；同值再按原始名称和 ID 稳定比较。不同文字的相对顺序由语言设置决定，不额外指定字符类别优先级。文件夹始终置顶；修改时间按真实时间值比较，缺失时间在各自类型分组内置后，同时间按文件名升序。
- 排序作用于完整数据，再筛选、虚拟化和分批；选择先后不决定预览顺序。切换目录、连接或设置页保留当前页面的排序设置，不写入后端偏好或 localStorage。
- 首次执行前可调整排序，保留任务成员和 before 快照，旧预览立即失效，必须手动刷新预览。执行期间禁止调整；任何已报告或未知批次都会锁定当前任务顺序，包括无变化确认和失败，结束任务后才可调整。执行后更新名称、修改时间或 Local ID 不重排任务。
- 预览响应、规则上下文索引及执行结果遵循提交的 ID 顺序；真实写入仍按后端临时名称、并发及回滚机制安全调度，不承诺完成先后。

### 设置、授权和目录

- 当前连接及各连接最后成功读取的规范位置通过 sessionStorage 保留，刷新后恢复；记录绑定连接 revision 与账号身份，有效记忆优先于默认云目录。浏览器存储不可用时提示并保留页面内存状态；不保存文件选择、预览、任务或凭据。位置恢复完成前暂停目录读取、展示与导航；新标签访问从默认入口开始，浏览器恢复关闭标签遵循其会话行为。
- 点击当前连接仅返回工作区，不重新初始化目录、选择或任务；设置页返回保留路径。连接删除、revision 或账号变化、确认断开授权时清理失效记忆；当前连接被删除后返回默认 Local。目录读取失败保留最后成功位置和错误；旧连接或旧版本的迟到响应不写入当前会话位置。
- 设置保存只发送修改字段，在同一 QueryClient 内串行处理；前一次失败不阻断后续保存，成功才更新缓存。设置 PATCH 不携带偏好版本字段；连接 revision 与预览校验继续保留。
- 后端是主题、分批提示和默认云目录的持久化来源，不导入旧 localStorage。system 跟随系统外观，不把解析后的明暗模式写回偏好。
- 界面语言同样由后端偏好持久化：`auto` 按浏览器候选顺序匹配，显式选择即时生效；缺失翻译与不可用语言回退 `en-US`，不可用的已存标识不自动改写。首次设置请求完成前只显示骨架，后续语言变化不重挂载工作区、不改变查询键、排序、选择、规则或任务；保存复用同一队列，失败回退，重置恢复 `auto`。语言目录通过 `meta.json` 与命名空间 JSON 自动发现。
- 默认云目录按连接与 `account_id` 匹配，不用邮箱或显示名替代身份。缺失 account_id 仍可浏览但不能保存默认目录；换号、断开、配置变化或删除连接清理旧默认值，同账号令牌轮换保留。恢复前暂停目录查询；目录失效保留错误和根目录恢复入口。
- OneDrive/Google 授权弹窗校验来源、窗口、消息结构与连接身份，前端不保存令牌。列表只展示连接状态，账号信息在编辑授权区；换号先断开再登录，读取中/失败不能误报未授权。
- 连接配置表单由 Provider 的 `config_fields` 驱动，支持文本、密码、目录字段；必填/空值、字段类型/target 和侧栏 icon 读取 Provider 元数据。服务名、账号缺省文案和字段文案仅按 provider_type/field.key 查询前端词典，不能由类型名推断业务能力；设置页以 `browser_auth`/`local_picker` 控制授权与目录选择。服务端同样按字段 target 判断密钥准入；仅适配现有字符串配置及顶层 `client_secret`，不实现完整 JSON Schema 表单；工作区同样消费 Provider 能力：browser_auth 控制授权和账号默认目录，local_picker 控制目录选择，locations 约束导航/恢复。元数据未就绪或失败暂停目录读取；无浏览器授权服务按连接版本恢复，需授权服务继续按账号/版本恢复，刷新失败保留已知任务和账号身份。
- Google 配置使用 Desktop Client ID 和明文输入的 Client Secret；密钥仅在请求顶层提交，响应只提供是否已保存，编辑留空保留。成功保存、关闭或切换新增类型清空密钥草稿，失败保留输入；配置不完整仍可保存，登录依服务端 configured 禁用。
- Google 导航完全消费服务端 breadcrumbs 中的真实 ID，不拆解显示路径；未提供该字段的 Local/OneDrive 保留现有路径导航。Google 默认目录和会话位置沿用账号/revision 隔离；快捷方式与 can_rename=false 的项不可选择，未知权限交由后端判定，只读文件夹仍能进入。用户配置与支持范围见 [README](../README.md#连接-google-drive)。
- 连接编辑保存后保留 Dialog；关闭仅丢弃未提交草稿，不撤回保存或即时操作。删除连接无需二次确认，仅默认 Local 禁止删除；删除配置/授权不删除文件。忙碌时禁用冲突操作和关闭。
- 本地选择器运行在后端机器。新增连接选择目录只填草稿，保存连接才持久化；编辑已有连接和工作区选择目录立即保存。取消保留原输入/工作区，新增浏览期间禁止保存、取消和关闭；远程或无桌面环境仍可手动输入路径。
- 首次默认根目录由后端选择系统 Documents，保留已有状态及环境变量覆盖，前端不推测系统路径。未提供完整面包屑的 Local/OneDrive 当前/上级使用服务端位置，更远祖先通过接口支持的 path 解析，不拼接云资源 ID；Google 使用完整服务端 ID 链。
- 恢复出厂设置须确认，成功后才清理任务、规则、缓存与路径会话记忆并返回默认 Local 根目录；只删除本功能的 sessionStorage 键，失败保留现有状态。未知结果未核对或操作忙碌时禁止重置；重置不删除真实文件，也不撤销重命名。

### 共享外观与反馈

- 共享控件使用 MUI 与语义主题颜色；菜单继承 `theme.ts` 与 `MENU_METRICS`，面板操作复用 `PanelIconButton`。布局、滚动与组件几何保留在针对性的 CSS/局部样式，不进行整体样式重写。
- 设置正文和控件文字使用 body2；授权第二行、状态标签、辅助说明、Alert 提示与 Tooltip 使用 caption。规则字段保持显式配置，NumberStepper 草稿不把暂时无效值写入规则。
- 表格虚拟化保留完整数据语义、固定选择列/复选框几何和键盘导航。长名称与错误在所属面板处理，不撑破页面；侧边栏名称仅实际溢出时启用完整名称 Tooltip。
- 正常预览不弹成功通知；冲突、无效名称与失败提供反馈，执行成功显示修改数量，部分失败与失败分别提示。新通知立即替换旧通知，保留上下文错误和逐项详情；后台刷新不反复弹成功通知。
- 前端固定 UI 文案按 common/settings/files/rules/providers/errors 命名空间维护，组件通过 react-i18next 订阅变化；模块常量保留翻译键，通知保留键、插值及原始错误，到展示时翻译。常见错误按 code 给出操作提示并保留诊断 message；未知错误不从句子推断类别。文件名、路径、连接名、账号及规则配置值保持原始数据。Rule 名称/说明按 `rules:types.<type>` 翻译，Provider/字段文案按 `providers:<provider_type>` 翻译；缺词回退 en-US，名称/标签最终显示稳定 ID，可选帮助缺失时省略。元数据 API 仅提供结构和能力；服务端 JSON Schema 的 title/description 不用作 UI 文案。`default-local` 等连接记录名保持用户数据，不以翻译覆盖或猜测别名。
- 首次加载、后台读取、未授权与读取失败明确区分；后台刷新保留旧内容，选择器取消不报成功。
