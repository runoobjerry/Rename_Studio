# 前端交接文档

## 定位与阅读入口

本文件说明前端模块职责、已实现能力和长期维护约定。实现事实以当前代码为准，依赖版本、控件尺寸、具体文案和测试覆盖分别查源码与专门文档，不在此维护副本；已实现不代表已通过运行验收。

接力时先读根目录与 `frontend/AGENTS.md`，再按需要查阅本文件、[API 契约](api/README.md)、[任务池](UI_TODO.md)和[当前快照](UI_STATE.md)，随后只读取目标模块及直接调用方。

## 模块职责与代码入口

以下路径均相对 `frontend/src/`。

| 入口 | 职责 |
|---|---|
| `App.tsx`、`WorkspaceApp.tsx` | 应用入口、Provider 组合、工作区/设置内存视图、布局、导航保护与跨 Hook 协调；没有 URL 路由或深层链接 |
| `workspace/hooks/useWorkspaceStorage.ts`、`workspace/workspaceSession.ts` | 连接与目录查询、本地根目录选择、默认云目录恢复/保存、标签会话路径记忆、手动刷新 |
| `features/rename/useRenameWorkflow.ts` | 对外工作流入口；当前目录的有序有效选择、批量预览生命周期、确认执行及单项/批量协调 |
| `features/rename/useSingleRename.ts` | 单项编辑会话、独立 API 请求、目录读取暂停、错误码提示、结果合并与未知结果保护 |

| `workspace/hooks/useFactoryReset.ts` | 重置禁用条件、请求状态、成功后的缓存和工作区清理 |
| `features/settings/{SettingsPage,StorageSettingsPanel}.tsx` | 外观、多连接配置、授权与重置确认 |
| `features/settings/{useAppSettings,useThemePreference}.ts` | 后端设置读取/串行保存、主题草稿与系统外观订阅 |
| `i18n/`、`locales/` | i18next 初始化、Vite 自动发现语言资源、按语言加载全部命名空间与缓存、浏览器语言解析、语言偏好及初次显示门控；日期格式化 |
| `../scripts/check-i18n.mjs` | 翻译资源、静态键和显式注册 Rule/Provider 的词条检查；PR CI 的离线检查入口 |
| `features/files/{FileBrowser,LocationBreadcrumbs}.tsx`、`fileSort.ts`、`defaultCloudLocation.ts` | 目录文件表、排序比较、筛选与选择、路径导航、默认目录账号匹配 |

| `workspace/components/{StorageSidebar,StorageLocationPanel}.tsx` | 侧边栏与目录操作展示；Drawer 容器由 WorkspaceApp 管理 |
| `components/`、`hooks/useVirtualTable.ts`、`theme.ts`、`styles.css` | 共享通知、筛选、图标按钮、表格虚拟化、主题与布局 |
| `api/client.ts` | 共享 HTTP 层和连接级 API 客户端 |

错误展示链路为 `api/client.ts` → `i18n/errorPresentation.ts` → `i18n/messages.ts` → i18next 资源。API 层保留诊断字段及读写性质；独立解析器只输出 UX 语义键和允许的展示参数，按“未知写入保护 → 匹配错误码的具体原因/请求字段 → 可选场景覆盖 → 通用类别 → 安全回退”解析。多个 API 类别可复用同一语义，新增语言只维护资源，不能展示后端原始 message。

统一入口保留 `errorMessage(error, t)`，有歧义时使用第三个参数 `directory`、`settings`、`connection` 或 `singleRename`。通知可使用 `{ error, errorContext }`，或在原有 `{ key, values, error }` 上附加 `errorContext`，保持显示时翻译。场景只覆盖少量通用类别，不按接口复制映射。示例：目录读取的 `PERMISSION_DENIED` 显示访问权限提示，默认重命名场景仍显示修改权限提示；5xx/响应丢失的写入始终先提示核对。

解析器不改变重试、任务状态或结果确定性；批量/单项的未知结果锁定、逐项 unknown/not_attempted 提示、设置保存与重置的专用核对提示继续由原业务模块负责。`details.params` 只允许文案声明的参数名和字符串/有限数值，字符列表及前缀仅格式化后用于插值，不作为 i18next 选项。

TanStack Query 管理服务端状态，Zustand 管理选择、规则、执行中的提交、最近修改记录和独立待核对信息。筛选留在组件，文件排序由 WorkspaceApp 保存在页面内存并显式传给工作流与表格，不修改目录缓存。连接与重命名 Hook 不直接互相调用，由 WorkspaceApp 显式传入数据及重置动作，展示组件不承载工作流状态机。

`useRenameWorkflow` 内部组合独立的单项与批量 Hook，保持工作台、Dialog 与测试的调用接口。单项自行请求 API，保留原生 `operation_id` 响应，仅通过回调使批量预览失效；互斥与连接上下文继续由工作流入口统一协调。

## 已实现能力与限制

- Local/OneDrive/Google Drive 多连接、目录浏览与刷新、文件/文件夹选择、面包屑导航、响应式侧边栏和设置页。选中文件夹只重命名文件夹本身，不递归处理内容。
- `padding`、`replace`、`remove`、`insert` 四种规则的字段编辑，以及启用/禁用、排序、复制、删除和清空。只展示前端已适配的规则；新增后端规则不会自动生成字段 UI。
- 服务端预览、冲突和无效名称展示、人工确认执行及逐项结果。每次预览对当前选择创建独立服务端快照，用户可以在预览后调整选择、规则或目录，提交不设文件数量上限；Provider 内部的分组、并发与限流机制保留。
- 文件和预览表已有虚拟化。选择、筛选、统计及列宽基于完整数据，不能只按挂载行计算；进度查询局部订阅，避免更新整个工作区。
- 文件名和修改时间支持表头升降序排序，预览使用同一顺序；具体约定见下方“选择、筛选和排序”。
- FileBrowser 唯一选中行在名称右侧显示 Edit 图标与重命名 Tooltip，支持文件和文件夹。Dialog 复用 MUI，应用按钮在校验和执行期间以 CircularProgress 替换文字，期间禁止编辑、重复提交及关闭；明确失败保留输入，成功关闭，未知结果保持待核对保护。
- 主题和默认云目录由后端应用设置持久化；选择、排序和最近修改记录只在页面内存，刷新即丢失。没有持久化历史、撤销/重做、规则集 UI 或搜索；目录接口无前端分页，云盘分页由后端聚合。

## 必须保留的业务与交互约定

### 预览和执行

- 规则批量改名先预览再确认执行，只提交服务端签发的 `preview_id`；单项快速改名直接提交文件身份、原名、完整目标名和连接版本，由独立服务直接调用 Provider，不创建预览、不读取整个目录或比对原名；Google 单项按 ID PATCH，由第三方判断是否允许，不读取祖先或执行 My Drive 范围预检，并采用第三方的同名语义。单项按统一错误码在名称输入框下显示提示，文件不存在时阻止继续应用，关闭后可重新选择；未知结果仍锁定两种流程。
- 连接、目录、账号、连接版本、选择或规则变化使旧预览失效；过时预览应释放，迟到响应不能覆盖当前上下文。切换工作区清理预览和选择，规则链、最近修改记录及尚未核对的执行信息保留。目录刷新发现已选项的名称或可选性变化时，旧预览失效。
- 单项与批量在提交时建立内存记录。收到逐项结果或无法确认写入时替换最近记录，服务端明确在写入前拒绝时保留上一条。选择、预览及工作区变化与记录生命周期分开，迟到结果仍记入发起操作的连接和目录。
- 自动目录读取仅在单项或批量写入请求在途时暂停，结束后恢复常规查询策略。执行中锁定目录导航及手动刷新。执行结果只合并 Provider 确认的 `current_file`，兼容 Local 路径 ID 改变，不按名称推断身份或成功。单项元数据允许缺少完整路径，显示路径由既有浏览上下文和确认后的名称生成，后续目录读取再更新，不作为资源身份或写入依据。
- 执行结束后可重新选择成功文件，再次修改须创建新预览。缺少执行结果或未知写入会阻止新的预览和执行；原连接和原目录的手动或自动读取成功后解除保护，恢复正常选择、单项改名和批量预览。旧预览与执行结果保留展示，旧预览不可执行。最近修改记录继续保留。
- 单项改名工作流只处理当前唯一选中项，文件分别编辑左侧主名和右侧扩展名，点号由界面补齐，扩展名可修改、添加或清空；文件夹只编辑完整名称。Dialog 不显示原文件名及说明文字，保留错误反馈；Edit 图标为 16px。单项修改保留规则链，确认元数据用于更新目录中的文件身份。成功后保持该项选择。打开或取消编辑保留批量预览和最近记录，提交时作废批量预览。缺少确认元数据的单项成功响应也进入待核对保护。
- 无名称变化时不启用执行按钮；已消费的预览不能复用。
- 进度来自只读服务端查询；轮询失败不重新执行、不模拟增长。已处理数量包含失败，进度完成不等于全部成功，逐项结果为准。
- 总体 status 仅使用 completed/incomplete，分别表示全部完成/未全部完成；counts 提供五种逐项状态的数量。执行项 status 直接使用 renamed/skipped/failed/unknown/not_attempted，前端不从错误码、文案、供应商状态或元数据缺失推导结果。执行后显示已确认当前名称；失败/未执行且未提供名称时明确显示名称未提供，未知显示待核对。错误字段见 [API 错误契约](api/common/errors.md#errors)，批次汇总及逐项状态见 [执行结果](api/executions/index.md#execution-outcomes)。
- 批量执行结束后立即关闭执行弹窗。结果通知仅分为全部完成的 success 和未全部完成的 warning，后者列出五种逐项状态的非零数量；响应丢失时显示待核对数量。未知结果在预览底部显示一条可关闭警告，关闭警告不清除待核对保护。执行前复核失败仍在弹窗提供重新预览入口。
- 单项目录归属优先比较 `directory_id` 与父目录 ID，否则比较同类型规范位置；仅确认同目录时沿用浏览路径并保留选择。归属不明时移除旧缓存项并在恢复自动读取时重新查询；读取失败保留错误，归属不明不等同于写入未知。
- 确认移走或明确 `NOT_FOUND` 的文件从当前目录和选择中移除。移走时提示位置变化，修改记录仍保存已确认的结果。成功自动关窗，`NOT_FOUND` 保留错误供关闭；关窗保留目录缓存及修改记录。

### 选择、筛选和排序

- 文件筛选清除隐藏项的选择，取消筛选不恢复旧选择。全选/反选只作用于全部可见且可选择的项目，替换选择集合；没有可选择项时禁用批量选择。
- 目录成功刷新后，选择与完整目录取交集；不自动选择新增项，读取失败保留选择。选择收缩使旧预览失效，但不重置进行中的执行请求与进度。
- 预览筛选仅影响显示，不缩小执行范围；执行结果中的失败/跳过分别归入错误/无变化，成功结果将待修改标签切为已修改。
- 文件类型筛选无勾选时显示整个当前目录。
- 排序复用 MUI TableSortLabel，箭头为 16px；默认完整文件名自然升序，Intl.Collator 使用浏览器语言列表（缺失时使用浏览器单语言，最后为 en-US），忽略大小写并按数字值比较；同值再按原始名称和 ID 稳定比较。不同文字的相对顺序由语言设置决定，不额外指定字符类别优先级。文件夹始终置顶；修改时间按真实时间值比较，缺失时间在各自类型分组内置后，同时间按文件名升序。
- 排序作用于完整数据，再筛选和虚拟化；选择先后不决定预览顺序。切换目录、连接或设置页保留当前页面的排序设置，不写入后端偏好或 localStorage。
- 预览或执行进行中禁止调整排序；其他时候可以调整，旧预览立即失效，切回旧排序也必须重新预览。执行后的名称、修改时间与 Local ID 更新参与当前排序。
- 预览响应、规则上下文索引及执行结果遵循提交的 ID 顺序；名称依赖在预览时判为冲突，真实写入按后端批量及并发机制调度，成功项保留且不自动回滚，不承诺完成先后。

### 设置、授权和目录

- 当前连接及各连接最后成功读取的规范位置通过 sessionStorage 保留，刷新后恢复；记录绑定连接 revision 与账号身份，有效记忆优先于默认云目录。浏览器存储不可用时提示并保留页面内存状态；不保存文件选择、预览、执行结果或凭据。位置恢复完成前暂停目录读取、展示与导航；新标签访问从默认入口开始，浏览器恢复关闭标签遵循其会话行为。
- 点击当前连接仅返回工作区，不重新初始化目录、选择或预览；设置页返回保留路径。连接删除、revision 或账号变化、确认断开授权时清理失效记忆；当前连接被删除后返回默认 Local。目录读取失败保留最后成功位置和错误；旧连接或旧版本的迟到响应不写入当前会话位置。
- 设置保存只发送修改字段，在同一 QueryClient 内串行处理；前一次失败不阻断后续保存，成功才更新缓存。设置 PATCH 不携带偏好版本字段；连接 revision 与预览校验继续保留。
- 后端是主题和默认云目录的持久化来源，不导入旧 localStorage。system 跟随系统外观，不把解析后的明暗模式写回偏好。
- 界面语言同样由后端偏好持久化：`auto` 按浏览器候选顺序匹配；缺失翻译与不可用语言回退 `en-US`，不可用的已存标识不自动改写。meta.json 与 en-US 回退词典预载，其余语言首次选用时加载该语言全部命名空间并缓存。首次设置与目标词典就绪前只显示骨架；后续加载保留当前工作区，完成后同步文案、document.lang 与 MUI locale，忽略过时选择。资源失败保留当前语言并提示刷新，不覆盖已保存偏好。切换不重挂载工作区、不改变查询键、排序、选择、规则或执行结果；保存复用同一队列，失败回退，重置恢复 `auto`。语言目录通过 `meta.json` 与命名空间 JSON 自动发现。
- 翻译贡献、术语和扫描边界见 [TRANSLATING](TRANSLATING.md)。en-US/zh-CN 完整维护，社区语言允许缺词但必须保留命名空间文件，CI 列出缺失键；JSON 结构/插值及默认静态/注册元数据词条错误阻止通过。任意动态键与浏览器布局仍须人工复核，不能把静态检查当作运行验收。
- 默认云目录按连接与 `account_id` 匹配，不用邮箱或显示名替代身份。已授权账号必须具有 account_id，不再支持缺失账号 ID 的旧授权；换号、断开、配置变化或删除连接清理旧默认值，同账号令牌轮换保留。恢复前暂停目录查询；目录失效保留错误和根目录恢复入口。
- OneDrive/Google 授权弹窗校验来源、窗口、消息结构与连接身份，前端不保存令牌。列表只展示连接状态，账号信息在编辑授权区；界面换号先断开再登录，读取中/失败不能误报未授权。授权开始本身保留已提交的账号；后端拒绝同一 Provider 的重复账号绑定，回调携带错误码及已有连接名称，仅在连接设置面板的 Alert 提示使用已有连接，保留当前连接配置及尚未被用户主动断开的原授权。授权发起及回调失败均只在面板显示错误，不显示错误 toast 或连接状态列的错误详情；授权成功仍显示成功通知。
- 连接配置表单由 Provider 的 `config_fields` 驱动，支持文本、密码、目录字段；必填/空值、字段类型/target 和侧栏 icon 读取 Provider 元数据。服务名、账号缺省文案和字段文案仅按 provider_type/field.key 查询前端词典，不能由类型名推断业务能力；设置页以 `browser_auth`/`local_picker` 控制授权与目录选择。服务端同样按字段 target 判断密钥准入；仅适配现有字符串配置及顶层 `client_secret`，不实现完整 JSON Schema 表单；工作区同样消费 Provider 能力：browser_auth 控制授权和账号默认目录，local_picker 控制目录选择，locations 约束导航/恢复。元数据未就绪或失败暂停目录读取；无浏览器授权服务按连接版本恢复，需授权服务继续按账号/版本恢复，刷新失败保留已知选择和账号身份。
- Google 配置使用 Desktop Client ID 和明文输入的 Client Secret；密钥仅在请求顶层提交，响应只提供是否已保存，编辑留空保留。成功保存、关闭或切换新增类型清空密钥草稿，失败保留输入；配置不完整仍可保存，登录依服务端 configured 禁用。
- Google 导航完全消费服务端 breadcrumbs 中的真实 ID，不拆解显示路径；未提供该字段的 Local/OneDrive 保留现有路径导航。Google 默认目录和会话位置沿用账号/revision 隔离；快捷方式与 can_rename=false 的项不可选择，未知权限交由后端判定，只读文件夹仍能进入。用户配置与支持范围见 [README](../README.md#连接-google-drive)。
- 连接编辑保存后保留 Dialog；关闭仅丢弃未提交草稿，不撤回保存或即时操作。删除连接无需二次确认，仅默认 Local 禁止删除；删除配置/授权不删除文件。忙碌时禁用冲突操作和关闭。
- 本地选择器运行在后端机器。新增连接选择目录只填草稿，保存连接才持久化；编辑已有连接和工作区选择目录立即保存。取消保留原输入/工作区，新增浏览期间禁止保存、取消和关闭；远程或无桌面环境仍可手动输入路径。
- 首次默认根目录由后端选择系统 Documents，保留已有状态及环境变量覆盖，前端不推测系统路径。未提供完整面包屑的 Local/OneDrive 当前/上级使用服务端位置，更远祖先通过接口支持的 path 解析，不拼接云资源 ID；Google 使用完整服务端 ID 链。
- 恢复出厂设置须确认，成功后才清理预览、选择、规则、缓存与路径会话记忆并返回默认 Local 根目录；只删除本功能的 sessionStorage 键，失败保留现有状态。未知结果未核对或操作忙碌时禁止重置；重置不删除真实文件，也不撤销重命名。

### 共享外观与反馈

- 共享控件使用 MUI 与语义主题颜色；菜单继承 `theme.ts` 与 `MENU_METRICS`，面板操作复用 `PanelIconButton`。布局、滚动与组件几何保留在针对性的 CSS/局部样式，不进行整体样式重写。
- 设置正文和控件文字使用 body2；授权第二行、状态标签、辅助说明、Alert 提示与 Tooltip 使用 caption。规则字段保持显式配置，NumberStepper 草稿不把暂时无效值写入规则。
- 表格虚拟化保留完整数据语义、固定选择列/复选框几何和键盘导航。长名称与错误在所属面板处理，不撑破页面；侧边栏名称仅实际溢出时启用完整名称 Tooltip。
- 正常预览不弹成功通知；冲突、无效名称与失败提供反馈，执行成功显示修改数量，部分失败与失败分别提示。新通知立即替换旧通知，保留上下文错误和逐项详情；后台刷新不反复弹成功通知。
- 前端固定 UI 文案按 common/settings/files/rules/providers/errors 命名空间维护，组件通过 react-i18next 订阅变化；模块常量保留翻译键，通知保留键、插值及原始错误，到展示时翻译。常见错误按 code 给出操作提示并保留诊断 message；未知错误不从句子推断类别。文件名、路径、连接名、账号及规则配置值保持原始数据。Rule 名称/说明按 `rules:types.<type>` 翻译，Provider/字段文案按 `providers:<provider_type>` 翻译；缺词回退 en-US，名称/标签最终显示稳定 ID，可选帮助缺失时省略。元数据 API 仅提供结构和能力；服务端 JSON Schema 的 title/description 不用作 UI 文案。`default-local` 等连接记录名保持用户数据，不以翻译覆盖或猜测别名。
- 首次加载、后台读取、未授权与读取失败明确区分；后台刷新保留旧内容，选择器取消不报成功。

### 外部浏览器导航

共用入口位于 `src/integrations/browser/`：消息桥安装一次，`useBrowserNavigation` 接入工作区，注册适配器负责解析与账号/目录语义。Provider 通过 `browser_navigation` 声明适配器 ID，缺失、为空或未知时拒绝外部导航，禁止根据类型名猜测；OneDrive 声明 `onedrive_personal`，Google 声明 `google_drive_my_drive`。`useWorkspaceStorage` 使用中立目标管理读取、恢复、取消、缓存和失败重试，不再依赖 CID 或 drive_id 字段。v1 OneDrive 请求保持兼容。协议见[浏览器消息协议](BROWSER_PROTOCOL.md)。
