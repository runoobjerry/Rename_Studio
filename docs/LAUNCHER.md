# 发布包启动与日志

[开发文档索引](README.md) · [开发与发布](DEVELOPMENT.md) · [后端测试与验收](backend/TEST.md)

安装 Python 3.12 或更新版本，完整解压对应系统的发布 ZIP。在解压目录内打开交互式终端，运行对应命令。

| 系统 | 普通模式 | 调试模式 |
| --- | --- | --- |
| Windows PowerShell 5.1+ | `.\Start.ps1` | `.\Start.ps1 -Debug` |
| macOS Bash | `bash Start.sh` | `bash Start.sh --debug` |

指定 Python 解释器时，传入完整路径。Windows 使用 `-PythonPath`，macOS 使用 `--python`。手动打开浏览器时，分别使用 `-NoBrowser` 或 `--no-browser`。

默认页面为 `http://localhost:8000`。在启动终端按 **Q** 或 **Ctrl+C** 安全退出。退出时等待正在处理的请求完成。更新应用前先退出，再替换程序与完整前端产物，保留用户状态、`.env` 与 `.runtime/`。

## 查看日志

导致启动失败的错误会在终端显示。服务就绪后，终端会显示当前版本、浏览器地址和本次 `app.log` 的路径。

### 日志内容

| 位置与内容 | 普通模式 | 调试模式 |
| --- | --- | --- |
| 终端 | 启动检查和错误。重命名提示包含文件源名称、批量进度及结果摘要 | 与普通模式相同 |
| `app.log` · 后端与业务 | `INFO` 及以上。记录服务启停、文件源与授权操作、目录读取、预览与重命名摘要，以及警告和错误 | 增加 `DEBUG`。记录缓存命中与失效、规则计算、执行前复核、分组调度、Provider 请求与重试 |
| `app.log` · HTTP 请求 | 记录 `4xx`、`5xx`、未处理异常，以及耗时至少 1 秒的成功请求 | 补充其他成功请求，适用下方的省略规则 |
| `app.log` · 排查字段 | 异常类型和适用的应用错误码。用 `operation_id` 关联预览与批量执行，或追踪单项重命名 | 增加 `request_id` 以关联同一 HTTP 请求。错误日志可附应用模块和行号 |

两种模式均省略健康检查、进度轮询、授权状态查询、文件源列表和未匹配路由的成功请求。HTTP 日志使用路由模板。文件日志省略凭据、Token、文件名、用户路径、查询参数和请求体。

## 保留策略

文件日志位于 `.runtime/logs/session-*/app.log`。准备启动后端时创建会话，保留最近 10 个。正在写入的会话会延后清理。旧版散放的日志和用户放入的其他文件由用户管理。
