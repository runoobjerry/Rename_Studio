# UI人工验收清单

更新日期：2026-10-25。本文件维护可复用的操作方法与通过标准，具体版本的验收结果见 [当前快照](UI_STATE.md)。

## 人工验收方法

相关 UI 修改后检查对应项目；发布前完整检查。以下检查使用浅色与深色主题各执行一次，至少检查桌面宽度和窄窗口。纯视觉验收观察预览即可；涉及执行的条目使用专用测试目录和临时文件。

| 编号 | 操作 | 通过标准 |
|---|---|---|
| UI-01 | 打开普通菜单、设置页主题 Select、文件/预览筛选菜单和添加规则菜单 | 内外间距、行高、字号与圆角协调；无文字截断或异常空隙；无需逐像素匹配旧断言 |
| UI-02 | 查看筛选按钮；选中一个选项，再取消全部选项 | 未启用时为中性图标，启用时为强调色图标；状态清楚，尺寸不跳动 |
| UI-03 | 鼠标悬停未启用的筛选按钮 | 显示说明未启用状态的 Tooltip；浅色/深色下均可读 |
| UI-04 | 查看文件区的返回上级、刷新、反选与筛选工具栏 | 图标大小和间距一致，布局无异常；全选入口在表头，无重复全选按钮 |
| UI-05 | 浏览小目录，再浏览超过虚拟化阈值的大目录；全选、取消选择，再切回小目录 | 复选框不拉伸，列和文字不明显跳动；大目录滚动时布局稳定 |
| UI-06 | 查看规则区操作按钮，打开添加规则菜单并悬停规则项 | 一键清除在添加规则之前；Tooltip 显示规则说明，无遮挡或截断 |
| UI-07 | 进入尚未生成预览的工作台 | 有清楚的预览说明，提示预览不会修改文件，存储名称正确 |
| UI-08 | 通过保存偏好等安全操作触发通知，旧通知消失前再触发新通知 | 新消息立即可见，旧消息平顺淡出；无重叠、闪烁或残留遮挡 |
| UI-09 | 通知出现后手动关闭；分别观察成功和错误通知自动关闭 | 手动关闭动画自然；自动关闭约五秒后发生，动画结束无残留通知 |
| UI-10 | 缩窄窗口并浏览较深目录；检查较长的规则菜单（如当前规则不足八项，记录未适用） | 当前目录仍可辨认，菜单可滚动，选项不会丢失；这是保留自动化测试之外的浏览器补充检查 |
| UI-11 | 在专用测试目录选择超过 1000 项，刷新预览 | 无分批提示，预览包含全部选中项；观察响应时间和内存，不将移除上限视为性能问题已修复 |
| UI-12 | 在有任务的工作台点击“浏览…”；分别取消与确认新的测试目录 | 取消保留当前任务和预览；确认后回到新根目录并清空旧选择 / 任务 / 预览 |
| UI-13 | 使用测试文件目录观察部分执行结果与目录 / 偏好读取失败时的界面（可借助开发环境模拟） | 结果、错误和“待核对”状态可辨认；不会显示可直接重复执行的过期预览；错误提示不遮挡操作。不要为验收故意中断真实云端执行 |
| UI-14 | 用鼠标及键盘操作文件名/修改时间表头；包含数字名称、同分钟不同秒、缺失时间与文件夹；大目录滚动后切换排序 | 升降序及箭头/表头语义正确；文件夹置顶、缺失时间在分组末尾；返回列表顶部，完整集合的全选/反选保持正确；明暗主题、窄窗口下箭头、日期和名称不挤压 |
| UI-15 | 先选择 001.jpg 再选择 002.jpg，文件名倒序后刷新预览；改变排序再切回并重新预览；在专用测试目录执行后重新选择成功项 | 预览按 002.jpg、001.jpg 显示；排序变化使旧预览失效；执行后仍可调整排序，成功文件可重新选择并重新预览 |
| UI-16 | 在设置中切换简体中文 / English，再检查文件表、规则字段、预览、确认框、筛选菜单、通知与键盘可访问名称 | 固定 UI 与 Rule/Provider/字段文案随语言更新；文件名、路径、连接名、账号及规则输入保留原值，默认 Local 的已保存连接名不改写。切换不生成预览或执行，不改变排序、选中项和任务；日期语言跟随界面，构建时间保留上海时区 |
| UI-17 | 编辑测试连接但不保存，在 auto 模式切换浏览器语言或由开发环境模拟语言变化后检查草稿；通过安全操作或开发环境模拟触发含数量/错误详情的通知后切换语言 | 草稿和弹窗保留，通知文案及插值正确，不显示 HTML 格式化的用户数据。常见错误具有当前语言的提示，原始诊断仍可见；未知错误不被错误归类 |
| UI-18 | 选择部分文件刷新预览，修改规则后重复预览/执行，手动刷新目录，再结束任务 | 当前任务始终只显示首次选定成员；原始快照不被重复执行覆盖，成功成员仍可重新选择；缺失成员不可提交；结束后回到完整目录，无 1000 项上限或跨批处理 |
| UI-19 | 模拟未知或缺失执行结果，结束任务、切换规则或连接后再尝试操作；核对实际文件后明确确认 | 新预览和执行保持锁定；取消核对不解除保护，明确确认后清空选择并要求重新预览；不自动重放写入 |
| UI-20 | 单选文件或文件夹后悬停名称右侧 Edit；改为未选、多选；检查长名称、窄窗口和虚拟列表滚动 | 单选时只显示对应行的 Edit 和重命名 Tooltip，其他情况隐藏；不增加行高，名称正确截断；点击编辑不改变选择或进入目录 |
| UI-21 | 用临时文件 archive.tar.gz、README、.env 及目录 folder.v1 打开重命名，取消后重开，再修改并应用 | 文件左侧输入主名、右侧输入扩展名（如 archive.tar 与 gz），扩展名可修改、添加或清空；文件夹仅输入完整名称；无原文件名或额外说明。打开期间暂停目录自动刷新，取消不写入且丢弃草稿，成功关闭并保持新文件身份选中；任务内操作不覆盖原始快照 |
| UI-22 | 使用测试目录或开发环境模拟较慢单项执行、名称冲突及未知结果；在任务内打开/取消及提交单项改名 | 单项只发一次直接执行请求，服务端复核与执行期间“应用”文字替换为圆圈，输入、取消、Escape 和点击遮罩关闭被禁用；明确失败恢复按钮并保留输入；未知结果禁止再次提交。打开/取消保留批量预览，提交后批量执行须重新预览 |

动态元数据文案还应检查：中英文下新建/编辑 Local、OneDrive 和 Google Drive；新增与普通/已保存密钥帮助分支正确，配置 key/value 不随显示标签变化。开发环境模拟未知扩展时，名称和字段缺词显示稳定 ID，已有英文资源可回退，业务能力不因缺词改变；不要为此操作真实 OAuth 凭据或云端文件。

翻译贡献还需按 [TRANSLATING](TRANSLATING.md) 在 en-US/zh-CN 和新增语言下检查 MUI 自带文案（排序、面包屑折叠、通知关闭）、ARIA、空状态、已知/未知错误及日期/数量。用宽屏和 320/375/768px 窄窗口检查长标签、菜单、抽屉、表格滚动及确认框，记录实际问题；静态扫描和 JSDOM 不能证明移动端或视觉通过。新增社区语言缺词应显示英文，不能显示原始翻译键。

触屏设备没有鼠标悬停时，Tooltip 项可记录“未适用”；图标状态、菜单布局和通知仍需检查。

## 保留的自动化保障

- 执行前确认、取消不执行、执行期间控件禁用。
- 筛选与全选使用正确 ID，包括虚拟列表未挂载的文件。
- 全量选中项提交、未知结果锁定、成功项重新选择后必须重新预览。
- 连接/账号隔离、迟到响应处理和预览释放。
- 偏好保存、保存失败和快速编辑竞争。
- 恢复出厂设置的成功、取消及失败处理。
- 通知独立计时器、同次渲染消息竞争和错误信息。
- 当前目录保留、菜单溢出和虚拟列表键盘导航。

## 自动化验证状态

遵循仓库半自动流程，本地 npm 安装、测试、类型检查、构建和浏览器验收由用户执行。结果及对应工作区范围统一记录在 [当前快照](UI_STATE.md)，本清单不维护通过状态；源码与覆盖对应关系的静态核对不能代替运行验证。

合并前运行 `cd frontend && npm ci && npm run check`，按相关人工清单验收并审查 PR Checks。PR 中的 CI 结果是提交对应的实际验证记录；若失败，应根据日志修复，不通过删业务断言或放宽超时掩盖。
