## 当前落点

- 单项快速改名直接提交执行，在服务端锁内复核最新源项、连接版本、名称、权限和冲突，不再创建预览；原批量预览及 preview_id 执行流程保持兼容，无状态格式迁移。
- 普通目录和固定任务内均支持单项改名；任务成员、原始 before 快照和其他成员结果保留，确认的文件身份与选择随结果更新。打开/取消不影响批量预览，提交时才使其失效。
- FileBrowser 唯一选中行显示 16px Edit 与 Tooltip；MUI Dialog 将文件主名和扩展名分为左右两个输入框，文件夹编辑完整名称，移除原文件名及说明文字。打开 Dialog 起暂停目录自动刷新；应用期间圆圈替换按钮文字，锁定输入与关闭，失败保留草稿，未知结果阻止再次写入。
- 工作流按职责拆分：`useRenameWorkflow` 负责批量流程及协调，`useSingleRename` 负责单项流程，`useRenameExecution` 共用执行请求和结果处理。长期约定见 [HANDOFF](FRONTEND_HANDOFF.md)，当前保留的自动化覆盖见 [测试清单](FRONTEND_TEST_CASES.md)，可复用 UI 验收步骤见[人工清单](UI_MANUAL_ACCEPTANCE.md)。
- 云目录重新进入测试改为验证连接切换、目录恢复及有效缓存复用，不再依赖全局最后一次目录请求的顺序。
