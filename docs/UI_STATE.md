## 当前工作

- StorageSettingsPanel：多连接管理、执行忙碌保护、弹窗来源/连接校验、关闭反馈和删除确认。
- FileBrowser：文件夹/父目录位置导航；保留刷新后失效选择清理和筛选隐藏项清理。
- 后端连接、迁移、认证与 Preview/Execute 进度见 MULTI_STORAGE_REFACTOR.md；接口见 API_REFERENCE.md。
