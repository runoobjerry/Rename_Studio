# 阶段性临时文档

[文档索引](../README.md) · [开发行为规范](../../AGENTS.md) · [系统架构](../ARCHITECTURE.md)

本目录存放复杂阶段性任务产生的临时计划、分析、交接与验收记录。它是被索引的工作资料，不是自动授权任务池或长期规范；简单任务不必创建文档。

## 当前索引

当前无待接续的阶段性任务文档。

## 创建与维护

- 使用 `YYYY-MM-DD-topic.md` 或 `YYYY-MM-DD-topic/README.md`，主题和边界明确；本页登记任务链接、状态与一句范围说明，任务页返回本索引并链接关联的长期文档和代码。
- 长任务拆成可验收阶段，记录当前阶段、已做决定、变更文件、阻碍和下一步，避免下一位开发者依赖聊天历史猜测状态。
- 验证证据绑定日期、提交或工作区、执行者、命令/场景和结果，分别记录实现进展与验收状态，状态使用“未执行 / 静态核对 / 通过 / 部分通过 / 失败”。用户执行本地验证，权限见 [AGENTS](../../AGENTS.md)。
- 稳定结论迁入负责该主题的架构/约定/API 文档，任务页改为引用；完成或取消后清理临时文档与索引项，必要历史由 Git 保留，不无限追加工作日志。
- 不存放真实凭据、用户文件内容、未脱敏请求响应或大体积构建产物；只保留任务需要的诊断与可追溯证据。

## 最小记录模板

按任务需要删减字段，不为填写模板制造步骤。

```markdown
# 任务名称

[临时文档索引](README.md) · [相关长期文档](../ARCHITECTURE.md)

## 范围与验收条件
目标、明确的行为标准、边界。

## 当前状态
日期；分支/提交或工作区范围；当前阶段；实现与验收分别说明。

## 决定与代码入口
必要决定及原因；受影响代码和契约的相对链接。

## 进展与验证证据
执行者、命令/场景、结果、环境；未执行项及原因。

## 阻碍与下一步
下一阶段、用户待验证事项、剩余风险。
```

模板按文件直接放在本目录编写；子目录内调整相对链接。新文档创建后必须在[当前索引](#当前索引)登记。
