# Frontend Agent Instructions

适用于 `frontend/` 下的 AI Coding Agents，与[根级指令](../AGENTS.md)共同使用。本文件只补充前端特有的执行约束；前端架构、UI、API 与测试等共享技术资料统一从[开发文档索引](../docs/README.md)定位，不在此重复维护技术文档目录或实现说明。

## 实现约定

- 遵守既有工作台容器、工作区 Hook、重命名工作流和受控展示组件的职责边界；跨模块状态归属以共享前端架构文档及当前代码为准，不在展示组件重复实现业务状态机。
- 区分服务端查询缓存、选择与规则状态、执行记录及组件局部展示状态。排序、筛选与虚拟化基于完整集合；文件显示名和 DOM 不承担资源身份或结果判断。
- 修改选择、规则、排序、连接、账号、revision 或文件身份时，同步处理预览失效、快照释放、迟到响应和缓存更新。未知保护独立于当前视图，切换页面或关闭警告不能清除；结果只合并服务端确认的元数据。
- 规则字段沿用现有显式适配方式；通用连接 UI 消费 Provider 能力与字段元数据。名称转换与冲突校验留在后端。
- UI 复用 MUI、主题和共享控件。固定文案、通知、Tooltip、ARIA 使用 `react-i18next`，同步维护 en-US / zh-CN；模块常量保存键，展示时翻译，文件名等用户数据保持原值。
- 错误展示从结构化字段选择提示，展示层不决定是否重试或改变执行结果。OAuth 保留来源、窗口和连接身份校验，令牌不进入浏览器持久化。

## 测试与收尾

按受影响行为选择检查；测试入口与编写约定从[开发文档索引](../docs/README.md)定位。交付时说明实际静态检查、用户待执行项与未验证范围；运行权限遵循[根级指令](../AGENTS.md#验证与交付)。
